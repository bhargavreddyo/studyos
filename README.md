# StudyOS

## Your Personal Study Operating System

StudyOS is a modern productivity platform designed to help students organize, plan, and optimize their study journey. It combines study planning, task management, goal tracking, Pomodoro focus sessions, notes management, and productivity analytics into a single unified dashboard.

Built entirely with HTML, CSS, and JavaScript, StudyOS provides a seamless and responsive experience while storing all data locally using LocalStorage.

## How It Works

1. Users create study plans and academic goals.
2. Tasks are added and organized by priority and deadline.
3. Pomodoro sessions help maintain focus.
4. Notes are stored and managed in the Notes Vault.
5. Analytics monitor productivity and learning progress.
6. All data is automatically saved using LocalStorage.
7. Users can continue their work even after refreshing the browser.
